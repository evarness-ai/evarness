# __tmpl_title

An Evarness channel plugin: __tmpl_summary. Generated by
`evarness plugin new __tmpl_name --kind channel`.

| File | What it is |
|---|---|
| `src/__tmpl_package/plugin.py` | the `__tmpl_tool` connector (an `IChannelConnector`: `name`, `send`, `healthy`) and `setup(api)` |
| `src/__tmpl_package/manifest.yaml` | the contract: `provides: [channel]` |
| `tests/test_plugin.py` | the connector alone, then a delivery through a real Evarness's gateway |
| `tests/test_stable_tier.py` | the plugin imports only Evarness's stable tier |

## Try it

```bash
pip install -e ".[test]"
pytest
```

The tests need no network: the connector delivers to a local outbox file in the Evarness
data directory. Once installed, add the plugin to a profile (`~/.evarness/profile.yaml`):

```yaml
plugins:
  - name: __tmpl_name
```
