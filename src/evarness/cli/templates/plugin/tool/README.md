# __tmpl_title

An Evarness tool plugin: __tmpl_summary. Generated by `evarness plugin new __tmpl_name --kind tool`.

| File | What it is |
|---|---|
| `src/__tmpl_package/plugin.py` | `setup(api)` registers the `__tmpl_tool` tool; `run(args)` is the call |
| `src/__tmpl_package/manifest.yaml` | the contract: the tool's `effect` and `content` |
| `tests/test_plugin.py` | the tool alone, then called by a scripted model in a real, governed Evarness |
| `tests/model_script.yaml` | what the scripted model answers |
| `tests/test_stable_tier.py` | the plugin imports only Evarness's stable tier |

## Try it

```bash
pip install -e ".[test]"
pytest
```

The tests need no model server and no network. Once installed, add the plugin to a
profile (`~/.evarness/profile.yaml`) and it mounts on the next start:

```yaml
plugins:
  - name: __tmpl_name
```

## Next

  `content: external` for one that returns text a third party wrote.

  `tests/test_stable_tier.py` holds you to it.
